## Case F-01
- 版本: A、B、E
- 頁面: Wind-Down
- 維度: 強制否決規則(HC-01)
- 判決: FAIL
- 嚴重度: 高
- 證據: Wind-Down 頁「minutes left」標籤文字與倒數數字重疊
- 原因: 屬功能性排版 bug,非品味判斷,直接影響可讀性
- 可遷移規則: 倒數容器必須採用 flex 或 grid 排版,數字與標籤之間保留固定間距,不可用絕對定位貼太近

## Case P-01
- 版本: C
- 頁面: 全局(色彩系統)
- 維度: 背景與輔助色和諧度
- 判決: PASS(5分,最佳參照)
- 嚴重度: —
- 證據: 湖水綠主調背景,輔助色與背景色相相鄰,深度與明度階梯配合舒服
- 原因: 輔助色同背景色相相鄰,飽和度克制,無對比色衝突
- 可遷移規則: 輔助色應與背景同色系或相鄰色系,靠明度階梯做層次而非色相對比

## Case B-01
- 版本: E
- 頁面: 全局(色彩系統)
- 維度: 背景與輔助色和諧度
- 判決: BORDERLINE(4分,合格但非最佳)
- 嚴重度: 低
- 證據: 背景偏深藍,配湖水綠輔助色,色相關係屬相鄰色系,但整體偏冷、深度感稍遜於版本C
- 原因: 符合同色系原則,無違反強制規則,但冷暖搭配與深度感未達最舒適水平
- 可遷移規則: 相鄰色系合格,但需注意冷暖調性與背景深度的協調程度,作為次選參照

## Case F-02
- 版本: B
- 頁面: 全局(背景明度)
- 維度: 情緒安全感 / 背景明度取向
- 判決: FAIL(1-2分)
- 嚴重度: 中
- 證據: 整體背景太淺,同app情緒基調不夾;同時每個block有浮空陰影,質感不適合此app
- 原因: 淺色背景本身非絕對錯誤(見Case P-02),但缺乏足夠暗啞輔助色平衡淺色帶來的刺激感
- 可遷移規則: 淺色背景必須搭配暗啞、低飽和輔助色,不可搭配鮮豔色或高對比陰影

## Case P-02
- 版本: D
- 頁面: 全局(背景明度)
- 維度: 情緒安全感 / 背景明度取向
- 判決: PASS(4分)
- 嚴重度: —
- 證據: 白色背景,但button輔助色用偏暗、偏啡黃/土黃色,整體有禪修感
- 原因: 證明淺色背景可以合格,關鍵在於輔助色是否暗啞克制
- 可遷移規則: 淺底配暗啞土色系可達成平靜感,不限定必須用深色背景

## Case F-03
- 版本: D
- 頁面: 全局(元件造型)
- 維度: 圓角處理
- 判決: FAIL(2分)
- 嚴重度: 中
- 證據: button整體方正,稜角非round corner,顯得銳利
- 原因: 直角同「禪修/放鬆」情緒基調衝突,即使背景明度合格,此項獨立扣分不互相抵消
- 可遷移規則: 所有按鈕、卡片圓角半徑最少8-12px,絕對不可用直角

## Case P-03
- 版本: D
- 頁面: Wind-Down
- 維度: 強制否決規則(HC-01)相關/正面對照
- 判決: PASS(排版最佳參照)
- 嚴重度: —
- 證據: Wind-Down頁「minutes left」文字完全冇重疊,排版清晰
- 原因: 數字與標籤之間有明確間距處理,是唯一冇觸發HC-01嘅版本
- 可遷移規則: 其他版本嘅Wind-Down排版應參考版本D嘅間距處理方式

## Case P-04
- 版本: C
- 頁面: 記錄頁
- 維度: 記錄呈現模式創意度
- 判決: PASS(5分)
- 嚴重度: —
- 證據: 歷史記錄採用模仿Memo嘅呈現模式
- 原因: 相比純list呈現,Memo模式提升互動性同可讀性
- 可遷移規則: 記錄類歷史頁面優先採用卡片/便條式呈現而非純條列list

## Case P-05
- 版本: D
- 頁面: 全局(底部導覽)
- 維度: 操作直覺度(Active State)
- 判決: PASS(5分,最佳參照)
- 嚴重度: —
- 證據: bottom navigation被選中項目除咗bold icon同文字之外,上方加咗一點dot indicator
- 原因: 三層視覺區分(bold icon+bold文字+dot indicator)喺低光環境下最容易辨認active state
- 可遷移規則: 底部導覽active state應採用多層冗餘視覺信號,不應僅依賴單一顏色深淺區分
